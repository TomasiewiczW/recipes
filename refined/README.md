# Sprawdzone przepisy

Ten folder zawiera przepisy, które zostały ugotowane i dopracowane. Każdy przepis powinien mieć:

- dokładne ilości składników
- jasne instrukcje przygotowania i gotowania
- przewidywaną liczbę porcji i wydajność
- czas oraz temperaturę gotowania
- przydatne notatki z testów

Dla każdego przepisu utwórz osobny plik Markdown w tym folderze.
