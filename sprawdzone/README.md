# Sprawdzone przepisy

Ten folder zawiera przepisy, które zostały ugotowane i dopracowane.

Każdy przepis powinien mieć:

- dokładne ilości składników w jednostkach metrycznych
- jasne instrukcje przygotowania i gotowania
- przewidywaną liczbę porcji i wydajność
- czas oraz temperaturę w °C
- przydatne notatki z testów

Dla każdego przepisu utwórz osobny plik Markdown w odpowiedniej kategorii.
